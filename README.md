# The Family Regiment

A premium heritage apparel brand where every jacket tells a family's story.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion (planned)
- OpenAI API (planned)
- Stripe (planned)
- PostgreSQL (planned)

## Development

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the application.

## Vision

The Family Regiment allows customers to build a personalized family identity through:

- Custom family crests
- AI-assisted Latin motto generation
- Premium field jackets
- Embroidered heritage patches
- Interactive jacket customization
- Future heirloom products
